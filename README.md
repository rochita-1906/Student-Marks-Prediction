
# Student Marks Prediction Using Machine Learning

## Project Description
This project predicts student marks based on the number of study hours using Linear Regression.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Linear Regression

## Features
- Takes study hours as input.
- Predicts expected marks.
- Uses a machine learning model.
- Demonstrates supervised learning.

## How to Run
1. Install Python.
2. Install required libraries using:
   pip install -r requirements.txt
3. Run the program:
   python main.py
4. Enter study hours to predict marks.

## Algorithm
Linear Regression
